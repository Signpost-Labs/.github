### Stellar ecosystem project

</div>

Signpost helps communities follow project commitments, milestones, progress updates, supporting evidence, and responses — with publishing attributed to a wallet.

### Inside the repo

- **Commitments to evidence** — Projects publish milestones and updates; anyone can follow whether the work landed.
- **Wallet-attributed publishing** — Stellar SEP-10 authenticates a connected wallet, so activity is attributable without a password database.
- **Honest about attribution** — A wallet address is pseudonymous — it proves authorship, not identity or truth — and records are stored off-chain.

### On-chain on Stellar

Built for the **Stellar** network with **Soroban** smart contracts — transactions are public and auditable.
